# Fern UI

Lightweight UI kit built on CSS cascade layers, semantic HTML, and zero dependencies.

## Features

- **CSS Cascade Layers** — `tokens`, `base`, `components`, `animations`, `utilities`
- **Light/Dark** — all colors use `light-dark()` and adapt automatically
- **Sidebar Layout** — collapsible rail, two-level push panels, inline expandable sections
- **30+ Components** — buttons, cards, forms, tabs, dialogs, toasts, tables, and more
- **Tiny Footprint** — ~10KB CSS gzipped, ~3KB JS gzipped

## Quick Start

```html
<link rel="stylesheet" href="dist/fern.min.css">
<script src="dist/fern.min.js" defer></script>
```

Or install via npm:

```bash
npm install fern-ui
```

## Components

Buttons, Cards, Forms, Tables, Tabs, Accordion, Dialog, Dropdown, Alerts, Badges, Chips, Toast, Tooltip, Progress, Spinner, Skeleton, Avatar, Sidebar, Search, Timeline, Tags, Metrics, Status
