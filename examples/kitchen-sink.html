    What is Fern UI?

    Fern UI is a lightweight UI kit built on CSS cascade layers, semantic HTML, and Web Components. Zero dependencies, fully themeable.

    How do I install it?

    Include the CSS and JS files via CDN or install from npm. No build step required for basic usage.

    Does it support dark mode?

    Yes! All colors use CSS light-dark() and adapt automatically based on the color-scheme property.
