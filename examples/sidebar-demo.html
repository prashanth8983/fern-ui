Sidebar Patterns

Three sidebar behaviors: rail collapse, push submenu, inline expandable

Collapsible (Rail)

Click the chevron button on the sidebar edge to collapse it into an icon-only rail (72px). Click again to expand.

  • 260px → 72px animated transition
  • Text labels fade out, icons remain centered
  • Section headers and user info hide
  • Brand collapses to icon only
  • Submenus auto-close on collapse

Two-Level Push Panel

Click Services, Deployments, or API to see the submenu panel slide in between the sidebar and main content, pushing the page right.

  • Parent items show a right chevron (→)
  • Submenu panel pushes content via CSS grid transition
  • Primary nav stays visible while panel is open
  • Click back arrow or trigger again to close
  • Uses [data-submenu] + .sidebar-submenu

Inline Expandable

Click Networking or Customers — these expand children inline with a smooth slide-down animation.

  • Uses .nav-expandable with .nav-expand-trigger
  • Down chevron rotates on open
  • Children indented 20px and animated via max-height
  • JavaScript toggles .open class

HTML Patterns

<!-- Two-level trigger -->
<button data-submenu="my-menu">
  <span class="material-symbols-outlined">dns</span>
  <span class="nav-label">Services</span>
</button>

<!-- Push panel (sibling of aside) -->
<div class="sidebar-submenu" id="my-menu">
  <div class="submenu-header">...</div>
  <ul>...</ul>
</div>

<!-- Inline expandable -->
<li class="nav-expandable">
  <button class="nav-expand-trigger">
    <span class="material-symbols-outlined">
      network_check
    </span>
    <span class="nav-label">Networking</span>
  </button>
  <ul class="nav-expand-content"
      style="max-height:0">
    <li><a href="#">Domains</a></li>
  </ul>
</li>
